# 首版范围

确认日期：2026-09-07。

## 产品与交付

用于 GitHub README 的 Steam 个人展示工具。首版支持其他用户配置使用。
生成一张完整卡片，仅提供一种初始布局，各区域可独立关闭。
GitHub Actions 默认每天更新，支持手动触发；更新失败时保留上一张有效卡片。
凭据使用 GitHub Secrets，不写入公开配置。

## 卡片内容

顺序：身份与总览、最爱、最近在玩、累计时长排行、更新时间。

- 身份与总览：头像、昵称及基础统计；具体字段需先核实接口。
- 最爱：用户手动配置 App ID，按填写顺序展示；默认最多 3 款，可调整；
  每款支持可选短评。
- 最近在玩：默认最多 6 款，可调整；按最近两周游玩时长排序。
- 累计时长排行：可选区域，默认开启，默认最多 3 款，可调整。
- 各区域之间不去重。
- 显示最后成功生成时间。
- 排除列表仅影响最近在玩和累计时长排行，不改变最爱或总览统计。
- 首版提供浅色/深色预设和中英文，示例默认英文。

## 使用流程

用户复制示例 workflow，填写 Steam ID、展示配置和所需 Secrets，
生成卡片到自己的仓库，再由 README 引用。
更新计划由 workflow 管理，与展示配置分开。

## 配置边界

config.example.yml 已有 YAML 解析器和严格字段校验。
基础配置包括 Steam ID、语言、主题、区域开关、各区数量、
有序最爱列表及短评、游戏排除列表。
不在首版建设可视化配置编辑器或多布局系统。

## 技术核实范围

- Steam 身份、游戏库、最近两周时长和累计时长的接口、凭据与隐私条件。
- 最爱中未拥有的游戏如何获取名称和图片。
- 数据缺失、私密资料、空列表和部分请求失败时的显示及更新行为。
- 总览统计口径；成就全收集游戏数尚未承诺进入首版。
- 游戏图片的获取与使用条件，以及字体和图片打包方式。
- 输出格式及 GitHub README 的真实渲染、缓存、宽度和主题表现。
- workflow 的最小权限、输出路径及避免无变化提交。

## 验收标准

初始成功标准是：真实或明确标注的示例数据生成完整卡片，
在 GitHub README 中正常显示，最爱 3 / 最近 6 / 排行 3 的布局可读。
正式数据更新还需验证失败时不会覆盖上一张有效卡片。

## 当前状态

已完成 TypeScript / Node.js 首版：配置校验、Steam 接口适配、统计与筛选、
最爱与短评、封面缓存和降级、PNG 渲染、原子写入、CLI、composite action、
每日更新 workflow 示例、中英文说明及四种视觉样稿。

总览首版确定为接口返回的游戏数量、累计时长和近两周时长。
可配置数量范围 1–12，最爱可选 name 覆盖用于下架或受限游戏。

本地测试和浏览器验证见 validation.md。真实账号请求尚缺 Steam API key，
GitHub hosted CI 和实际 README 图片 CDN 链路需发布后验证。
